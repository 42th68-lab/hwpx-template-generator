# 양식 대리 생성 프로그램

제출 조건을 자연어로 입력하거나 PDF/HWPX 안내문을 첨부하면, 조건을 분석해 한글에서 바로 작성할 수 있는 HWPX 문서 양식을 생성하는 웹 서비스입니다.

## 핵심 흐름

1. 사용자가 문서 종류, 형식 조건, 필수 항목을 입력합니다.
2. 서버가 입력 문장과 첨부 문서에서 조건을 추출합니다.
3. 추출 결과를 구조화된 문서 설정값으로 보여 줍니다.
4. 사용자가 설정을 확인하거나 수정합니다.
5. 검증된 기본 HWPX 템플릿에 설정을 적용해 새 파일을 만듭니다.
6. 결과를 미리 보고 HWPX 파일을 내려받습니다.

## 개발 단계

- 1차시: 서비스 세부 기능과 IPO 확정, 저장소 준비, HWPX 구조 조사
- 2차시: 요구사항 입력 화면 제작
- 3차시: 자연어 및 PDF/HWPX 입력 처리
- 4차시: 문서 설정 변환 및 기본 HWPX 생성
- 5차시: 결과 미리보기와 최초 배포
- 6~8차시: Supabase 저장, 공개 범위, 불러오기와 전체 테스트

## 1차시 결과물

- [한글·Word에서 여는 1차시 결과 문서](1차시_서비스_IPO_HWPX_구조조사.docx)
- `scripts/inspect-hwpx.mjs`: HWPX 패키지의 파일 목록과 핵심 XML 구조를 확인하는 무설치 검사 도구

## 조사 도구 실행

Node.js 18 이상에서 다음과 같이 실행합니다.

```powershell
node scripts/inspect-hwpx.mjs "검사할파일.hwpx"
```

검사 도구는 원본 HWPX를 읽기만 하며 수정하지 않습니다.
